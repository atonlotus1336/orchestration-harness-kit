# Codex adapter

This adapter translates Codex thread, turn, item, tool, and lifecycle
notifications into the universal orchestration protocol. Native Codex events are
transport signals, not proof that the SDK authorized a native action.

The predecessor's server-owned mediation and honest native-bypass labeling are
preserved as contract intent. Routing, authority, capability discovery, memory,
retrieval, token-compute optimization, and provider accounting stay in the
shared core. Source qualification does not change Codex configuration or run a
model request.

```text
python modules/conformance-kit/run-conformance.py --harness-dir modules/adapters/codex
```
