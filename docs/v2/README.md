# Universal Orchestration SDK v2

This directory records the public design and release evidence for the v2 SDK.
The SDK keeps policy and orchestration in a shared core while harness-specific
adapters translate local capabilities into one versioned protocol.

Current status: design and provenance qualification. No v2 runtime activation is
implied by files in this directory.
