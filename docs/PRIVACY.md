# Privacy statement

This kit ships code and empty templates. It does not need or include the
maintainer's projects, credentials, memories, machine identity, or runtime
state. The client bundle intentionally omits Git history and the optional owner
system snapshot.

Your memory data remains in the data directory you select. Install and update
operations never delete that directory. Do not place credentials in the kit
directory or commit local configuration. Use environment variables or your
operating-system credential store.

Before sharing a bundle, maintainers must run the payload builder and privacy
canary tests. A clean source repository alone is not release evidence.
