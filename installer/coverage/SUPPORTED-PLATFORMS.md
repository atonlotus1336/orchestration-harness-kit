# Supported platforms

| Platform | Status | Required evidence |
|---|---|---|
| Windows 11 with Python 3.11+ | Supported core | install, doctor, rerun, uninstall |
| Ubuntu 22.04/24.04 or WSL2 | Supported core | install, doctor, rerun, uninstall |
| macOS with Python 3.11+ | Experimental | same clean-machine evidence before support claim |

Optional services have separate prerequisites and do not change core status.
