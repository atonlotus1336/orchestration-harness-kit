# Supported platforms

| Platform | Status | Required evidence |
|---|---|---|
| Windows 11 with Python 3.11+ | Qualified | Phase 80 native clean-clone nine-gate receipt |
| Ubuntu 22.04/24.04 or WSL2 | Qualified | Phase 80 Linux/WSL clean-clone nine-gate receipt |
| Docker Linux container with Python 3.11+ | Qualified at Phase 81 completion | clean-container lifecycle and artifact receipt |
| macOS with Python 3.11+ | Experimental | matching clean-clone evidence before support claim |

Optional services have separate prerequisites and do not change core status.
Platform qualification covers the provider-free SDK, not live provider or
harness activation.
